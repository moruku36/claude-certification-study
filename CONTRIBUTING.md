# Contributing

Keep English and Japanese content aligned. Use synthetic data only. Do not submit exam dumps, recalled items, screenshots of exams, or copied course/sample-question content. Link primary sources and record the verification date. Distinguish facts, discrepancies, and our teaching recommendations. Recheck guides before changing domain weights. Run `python scripts/check_docs.py` and `python exercises/offline_lab.py`, then inspect the diff. No dependencies or API keys are needed for those commands.

日英の内容を合わせ、架空データだけを使ってください。試験流出問題・記憶再現・試験画面・講座やサンプルの転載を提出しないでください。一次資料と確認日を記し、事実・差異・独自提案を区別して、領域配点変更前にガイドを再確認してください。
