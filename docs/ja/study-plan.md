# 4週間の学習計画

非公式・独自作成教材。Anthropic / Pearson VUE の承認や提携はありません。合格を保証しません。確認日: 2026-10-13

独自の計画。週5日、1日45〜60分を目安にし、経験に合わせて延長する。試験準備完了を保証する時間数ではない。

| 週 | 作業 | 完成物 |
|---|---|---|
| 1 | 受験資格・試験ガイド確認、M01〜M04、L01〜L04 | 要約プロンプト、評価基準、モデル比較、資料台帳 |
| 2 | M05〜M08、L05〜L08 | ループ図、API復旧表、ツール契約、リポジトリ規約 |
| 3 | M09〜M10、L09〜L12 | 検証器、リスク表、設計判断メモ、引継ぎ記録 |
| 4 | 対象トラックの対応表で復習、問題を資料なしで解く、誤答を再説明 | 領域別の不足一覧と追加学習計画 |

- Associate: M01/M02/M03/M04/M09/M10を優先。業務導入と人へのエスカレーションを言語化する。
- Architect Foundations: M05/M07/M08/M09を優先。公式ガイドの詳細タスクを一つずつ説明・実装できるか確認する。
- Developer: 最大配点の連携(M06)を優先し、停止理由・ツール履歴・障害時の挙動を追跡する。
- Architect Professional: M10を中心に、設計・連携・評価・運用を結び付け、関係者に判断を説明する。

各日: 10分読む→25分演習→10分根拠を確認→5分不足を書く。英語用語を日本語で説明し、英語でも短く書く。
最終確認: 全領域について「判断・根拠・失敗ケース」を説明し、独自問題を正答できても公式合格の予測には使わない。実API・Claude Codeの演習はこの無料オフライン教材の範囲外。既存の許可済み無料環境がある場合だけ、費用・データ条件を本人が確認して追加する。
